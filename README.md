# Droplet Film Analysis

侧视液滴/液膜 BMP 图像序列识别与人工复核工具。

**工具版本：0.2.0｜识别算法：5.3.2｜单位：px**

本版修正新数据中壁面提前截断和接触后近壁轮廓被阴影规则切开的情况。实验验证范围见 `VALIDATION.md`，不代表对任意新拍摄条件的准确率。5.4 对照算法未纳入工具。

方法流程、测量定义和推断边界见 [METHODS.md](METHODS.md)。项目维护与发布规范见 [AGENTS.md](AGENTS.md)。本次整理仅更新方法／工具，不附带实验数据，不修改识别算法或默认参数。

## 本机使用

1. 双击 **启动工具.cmd**。
2. 粘贴或选择一个 BMP 图像目录，也可以选择包含多个图像序列的上级目录。
3. 点击“壁面预览”，检查第一组参考壁面与处理区域；确认后点击“开始识别”。处理完成后自动打开浏览器复核页面。
4. 运行时保持启动窗口打开，本机服务负责复核落盘；可以关闭浏览器，之后重新打开结果。

任务保存在本工具的 `runs/` 下，每次任务使用新的目录，不覆盖原图和旧结果。“停止”会在帧处理边界停止；“继续任务”会核对原图、参数和算法标识，跳过已完成组，重做中断组。已完成组失败重试不会覆盖已有成果。

2026-10-29 起，新任务目录带输入名称，每组输出目录带工况信息及唯一编号，例如 `65°__2.0mm_100mm_001__数据编号`。从输入路径提取已有的角度、视角及工况名，不猜测缺失信息。任务根目录的 `datasets.csv` 列出工况、输出子目录、完整原图路径及执行状态；每组另存 `来源说明.txt` 和 `source_info.json`。旧任务可保留原编号目录，使用来源清单检索。

本工具不需要 Node、不使用云端识别，也不读取之前研究项目的数据或标尺路径。本机 Python 路径可通过被 Git 忽略的 `local_python.cmd` 配置；其他电脑不依赖该文件。

## 其他 Windows 电脑配置

推荐使用带 tkinter 的 64 位 Python 3.13。取得代码后运行 **配置环境.cmd**，它建立本目录的 `.venv` 并安装依赖，然后运行“启动工具.cmd”。该脚本需要访问 Python 包源。`requirements-validated.txt` 记录本机检查环境的版本，`requirements.txt` 用于常规安装；其他依赖环境需自行验证结果一致性。

也可以手动运行：

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe launch.py --check
.venv\Scripts\python.exe launch.py
```

命令行批量入口：

```powershell
.venv\Scripts\python.exe launch.py --input "图像文件夹路径"
.venv\Scripts\python.exe launch.py --resume "包含 run.json 的任务目录"
```

## 输入要求

- 支持 BMP 序列。文件名以 `-数字.bmp` 结束，例如 `camera-0.bmp`、`camera-1.bmp`；按原始数字帧号排序，不重新编号。支持中文及含空格的路径。
- 每组直接放在一个文件夹内，组数由包含 BMP 的文件夹自动确定；同名子目录以相对路径区分。
- 每组至少 32 帧，尺寸一致，无重复帧号。缺帧会提示并保留真实帧号；部分依赖相邻帧的恢复会相应受限。
- 前 32 帧用于估计背景，需要能构建未润湿壁面的背景。启动检查不能保证背景在物理上完全正确，仍需检查壁面及撞击前后帧。
- 适用于当前侧视几何：靶体在右，液体主要在壁面左侧，壁面可表示为随图像 y 单调排列的曲线。不同视角、翻转方向或拍摄质量需重新验证。
- 默认在横向完整搜索区域内提取连续壁面，去除大幅跳到另一条边缘的行；处理区域默认包含完整图像宽度。上下与边缘仍保留必要的可观测范围限制，不强行把壁面外推到底边。
- 可选的 `video_param.json` 提供 `frame_rate`；没有帧率时保留帧序列，不猜测时间。
- 原图目录与工具 `runs/` 不得重叠。原始图像只读。

“壁面预览”读取所选目录中第一组的参考帧，不运行整段液膜识别，也不改动原图。批量数据仍需逐组核对结果中的 `wall_reference.png`。

特殊取景可通过“参数文件”加载 JSON 设置覆盖，或在命令行新任务中使用 `--settings 参数.json`。例如，对 1280×1024 图像指定搜索区域和处理区域：

```json
{"wall_search_roi": [12, 12, 1268, 1012], "roi": [0, 0, 1280, 1012]}
```

坐标顺序均为 `[left, top, right, bottom]`，右/下边界不包含；必须适合实际图像尺寸。`wall_points` 可提供至少四个不同 y 的 `[x,y]` 控制点。手动标定只适用于同一画面位置，不能把一组的壁面点套到位置不同的批量数据。加载文件后再次预览；继续旧任务不能更换参数。

## 测量定义与输出

- **主液膜**：完整连续的前部液体及附着延长尾部，内部白色反光作为液体内部；独立飞滴另存。
- **近壁补全**：独立接触证据连续确认后，仅补全由当前主液体轮廓和已观测壁面共同围住的近壁孔洞，限定在已接受接触跨度及壁外 7 px 内。开放的空气间隙不强制闭合；补全像素不作为接触证据或撞击种子。
- **细颈连接**：对已呈铺展形态的贴壁液体片段，仅在短间隔内存在连续、超过背景噪声的当前灰度路径时接回主液膜；新增重连不填补白色空气间隔。`gray_neck_bridge_area_px2` 和 `current_gray_wall_neck_connected` 记录连接处理。
- **最大厚度**：沿有效壁面外法线量到完整主液膜的外轮廓，测量线不得穿过估计固体。
- **实际铺展长度**：主液膜接触部分最外两端之间的壁面总弧长，接触证据的间断另外记录。
- **撞击位置**：首次接触帧的接触两端之间的壁面弧长中点，记录参考图像坐标及原图坐标，显示为点。
- 所有新任务、图表和导出均为像素单位，不提供毫米换算，不平滑结果曲线。

各组的 `measurements.json`、图像、掩膜和 `profiles.npz` 保存自动结果。`measurements.csv`、`postimpact_measurements.csv` 和总表 `parameters_all.csv` 只含有效撞击后帧。`all_frames_trace.csv` 包含全部源帧，其终止后暂存几何不能直接用于正式统计。

`observed_masks/` 保存近壁补全前的处理掩膜（仍含反光、时序恢复及灰度细颈连接），`contact_completion_masks/` 单独保存新增的近壁推断部分，`masks/` 保存最终几何。JSON 逐帧记录 `contact_completion_area_px2` 和两类诊断掩膜路径；CSV 的 `flags` 标识补全及厚度线经过推断区域的情况。推断轮廓连续不代表已证明每一点都真实润湿。

液膜到达有效壁面/处理区域下端后，仍可查看图像和追溯记录；正式序列按自动有效范围终止。无撞击或无有效数据时，正式表为空表，不以撞击前数值代替。

## 人工复核与导出

曲线位于顶部，可点击跳帧；图像与人工修正面板并排。可修改轮廓、接触段、最大厚度和撞击帧。

通过工具打开的页面自动保存到任务的 `reviews/state.json`，保存状态显示在页面中。磁盘记录是主存储；不同标签页版本冲突时提示刷新，不静默覆盖。保存失败时可先“导出当前组复核”备份。

数据集列表按路径中提取的角度、视角及工况名称中的数字自然排序，例如 100、200、1000 mm；同工况多次采集显示采集目录及签名短码。页面显示完整来源路径。通过工具打开时，页面只传输当前工况的完整轮廓和全批次的简短目录，切换前等待当前复核落盘；其他工况的轮廓仅在选中或导入相关复核时读取。切换仍需初始化当前工况的曲线、图像。离线合并 HTML 为独立文件，仍包含全部工况数据。

“修正结果保存到文件夹”将修正后的 JSON、正式 CSV、追溯 CSV、厚度及长度曲线保存到新的 `exports/` 子目录。自动识别文件不会被人工值覆盖。结果文件夹包含配准图与掩膜，应整组保留，便于移动后继续查看。

直接双击离线 `review.html` 时没有本机保存接口，只能浏览器暂存和手动下载复核备份。自动落盘需通过启动工具打开。

可以“打开历史结果”查看 V5 的完整结果目录。旧复核文件必须匹配对应结果的分析签名与坐标系；不能仅按帧号套到重新识别的新结果。旧浏览器中尚未导出的记录，应先导出 `all.review.json`，再在对应旧结果中导入。

## 版本与局限

`ENGINE_PROVENANCE.json` 保留 5.3.1 基线指纹，并记录 5.3.2 当前指纹及修改模块（`core.py`、`optical.py`、`v5.py`）。5.3.2 同时修改几何参考与近壁补全流程，不能作为旧算法的等价重跑。运行记录保存工具版本、算法标识、参数和输入指纹；软件或输入变化后不能续跑旧任务。旧结果可以继续打开复核，不能将旧复核记录直接套入新版识别结果。

长时间强反光、模糊壁面、近壁阴影和极薄尾仍可能识别有误。估计固体排除约束不代表真实物理壁面已被准确标定；自动异常标记也不等于已确认错误。请先用新数据核对轮廓和曲线，再决定是否用于批量研究。

仓库不包含实验图像、识别结果、人工记录、虚拟环境和本机配置。暂未添加开源许可证。

`src/droplet_analysis/` 保存数值方法及复核页面，`src/watercar_tool/` 保存操作界面、任务管理和本机保存服务，`tests/` 保存合成测试。实验运行产物、诊断目录及人工修正备份均排除在发布范围外。源码维护入口为 `droplet-film-analysis`；相邻的 `droplet-film-analysis-main` 仅作为发布副本。

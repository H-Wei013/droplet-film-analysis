绘制说明与保存方式

在中间或右侧图上绘制。接触段修改后长度立即更新；轮廓修改后厚度重算，人工厚度优先保留。通过工具打开时自动保存到结果目录；离线打开时请导出备份。

本帧数据与测量定义


最大厚度沿壁面法线量到主液膜的外轮廓，完整前端与贴壁尾部，内部反光亮区不截断厚度线；厚度线经过悬出区不等于该处与壁面接触。蓝线为主液膜接触两端之间的壁面总弧长；中间证据不足的部分单独标记。最大厚度覆盖完整主液膜。正式数值 CSV 仅含有效撞击后帧；全帧追溯 CSV 和完整追溯 JSON 包含撞击前、终止后暂存几何及状态，不能直接作为正式统计。复核记录用于恢复编辑。人工厚度优先于自动厚度；可单独撤销或标记无有效厚度。可一次导出当前页面包含的全部数据集中已有复核记录的组，保存为 all.review.json，也可导入该合并文件。最终数据 JSON 和 CSV 仍按当前组选取。
